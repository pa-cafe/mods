場景圖來自 Chromium WebGL2，使用正式街道渲染器、家具載入器、飛行鏡頭與各區的實際地標座標。前後對照固定在各關第一個地標。六關手機圖的 CSS viewport 是 390×700，桌面為 960×540。地標與轉場圖為 800×450。明信片經過遊戲的獨立 postcard 相機。遊戲圖來自隔離 Worker 的虛構咖啡館。

## 行為與限制

- 桌面、手機尺寸各實際繪製六關、最低品質與五個相鄰轉場。22 個地標逐一用正式地標位置取景；未在真實手機量測。
- 固定 v11 重播（seed 37，Claude、Dots，aim 18、hold 32、無 taps）在桌機與手機尺寸、網址 `&2d`、無 WebGL2、該關 10 件場景 GLB 全數下載失敗時均顯示 **5.70K**，與規則重算的 **5,701 tokens** 相符；五個案例無 page error。
- 原版端對端 driver 的三個所選流程未全部走通。分享首頁等待舊入口文字，重播流程等待「已複製連結」，設定流程的跳過導覽按鈕被 canvas 攔截。上述固定連結測試獨立驗證播放及結算。剪貼簿分享、設定按鈕點擊與實體手機仍是審閱缺口。
