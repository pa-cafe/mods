# 六關完整風格替換製作表

依據：使用者核准台北 v3，並要求「原版的都換掉」「不要新舊混雜」。已看六關遊戲原版／目前新版對照、台北 v3 固定鏡位、五關 v2 Blender 組裝圖；已讀 Codex 實際遊戲審閱（mods b6441c1、cafe bfaaea81），並取得最新 codex/blast-miniature-scenes 的 street3d-sets.ts。這不是已完成清單，也不是宣稱六關已驗收。

## 定義完成，避免再次只換地標

正常 3D 路徑須覆蓋每個 scene 的 6 個前景 slot（及 4 個變體）、每個 sight slot、behind、far、groundMarks、天空／雲／浮物、street furniture、車與所有遊戲道具外觀。幾何可保留合理共用拓撲，但外觀必須重新設計並記錄，不以單改 tint 算完成。每個 original builder 建立一列到新 asset/builder 的映射，無對應或仍會進舊 build 的列不能標完成。空的虛無前景應保持空，不為覆蓋率硬加建築。

範圍是 3D 場景，不替換已核准角色圖集、HUD、玩法規則。所有骨架／動畫曲線／隨機種子／道路 slot／遮擋判定／動態文字／粒子時序不因換模刪除。沒有旋轉的舊風機也不謊稱已有動畫；有動畫的物件必須分離 mesh 與 pivot，保持 pose/update API。

正常載入不得出現新舊外觀拼湊：建議每關按預算預載完整 style bundle 後原子切換。失敗時採同風格低模代用品或整關一致降級；若工程目前仍必須用舊程序 fallback，應獨立列為故障路徑／待改，不混稱「全部換完」。無 WebGL 和強制 2D 保留原規則與結果，但 2D 不是 3D 美術覆蓋證據。

## 共用製作層（全部六關）

- 材質：同一霧面陶釉／木材／塗漆金屬／石材 roughness 分組、適量 bevel、明暗層次與 emissive 上限。六關各自 palette，不全變米棕色。
- 地面：路面、路緣、人行道、接縫、車道標線與空間系轉換，7m/14m 接縫連續。視覺與碰撞仍分開。
- 街件：桌、椅、長凳、菜單牌、立招、箱子、盆栽、路樹、路燈、欄杆、販賣機、桶與袋。共用小屋資產需先逐件目視確認；不因來源是小屋就自動算升級。只改 Blast 實例或獨立資產，勿全域改家具影響小屋。
- 動態／遊戲道具：咖啡機、外帶窗口、quota wall、ban letter 及其他 place(props) 類型逐一從實際 registry 列出，保留 pose、光效、字樣、碰撞尺寸和狀態。不能只盤點建築。
- 天空：sky gradient、sun/moon/bean、clouds、floaters、星點、霧及曝光統一渲染語言；原轉場 wipe 和品質降級保留。

## 交接與驗收

每關建 checklist：original source/symbol → replacement asset/builder → variant coverage → runtime hookups → desktop/mobile evidence → fallback evidence。要求 6/6 near slots × 4 variants（虛無明確空槽）、所有 sights 與 behind、far、小物及 prop registry 無遺漏。

同鏡位截圖：每關至少所有 near/sight 變體，960×540、390×700，必要時橫屏／短屏；單件隱藏差分避免載入成功卻被遮到看不見。保留實際角色及 HUD 可讀性；不要 Blender 渲染冒充遊戲。

性能：同 WebGL renderer、DPR、品質、seed／鏡位量測 draw calls／triangles／每關 GLB 網路量，須比較基線；真手機 FPS 未測就寫未測。規則 regression、固定 replay 結果、轉場、postcard、低品質、單件／整組失敗、2D fallback 都要測。新舊不能正常混搭，但也不能以美術重製名義移除原玩法或錯誤回復。

目前缺口：未完整讀取最新 props/gags registry 所有符號，尚需 coding agent 列出精確清冊；已有 40 件 v2 模型僅部分採用，必須逐件對照才可標重用；本文件與新竹六件尚未接入 repo。沒有合併／部署。
