# 台北 v3：前景街景＋101風格改造，固定鏡位審視稿

**本包不是遊戲截圖，不是已整合版本。未改repo、未合併或部署。**

這輪不擴六關。先核對已有台北v2、修正版中正紀念堂、捷運資產，避免重做已有修正；再針對先前只換少數地標、街景仍原樣的問題，真正重建最佔畫面的前景7m節塊。

## 這次真正新建／改造的5件

1. `tpe3_corner_cafe_7m`：雙層拱窗、放射/縱向窗格、厚窗台、百葉窗、三段條紋遮棚與扇形邊緣、凸出咖啡杯招牌、立面層次。
2. `tpe3_tea_balcony_7m`：較低綠色茶屋、架空店面柱、連續陽台、垂直茶招牌、屋頂水塔與加蓋，與咖啡館不同輪廓。
3. `tpe3_arcade_apartment_7m`：較高紅磚公寓、側邊低附樓、小陽台、遊戲招牌與燈泡，形成街道高低節奏。
4. `tpe3_low_market_7m`：單層小攤、座椅、植栽與空白間距，不再用同高店屋排滿；為捷運／後層地標留視線。
5. `tpe3_101_jade_refined`：保持101八節竹節輪廓，但重做倒角多邊塔身、外擴簷口、深玉色窗格與暖色窗燈、香檳色邊條。高93.7m。

主方向是奶油／深木／鼠尾草綠／陶紅的柔邊微縮街景，而非用同一組方塊改顏色。這仍需使用者視覺審核，不能把「新增幾何」等同於風格已被核准。

## 正確的兩種接入尺度

- 四個前景節塊**直接以公尺建模**，沿街寬7m，原點底中心，GLB Y-up/+X沿街/+Z朝玩家。放在`x=7*i+3.5,z=-8,y=0`時主立面約在原FACE=-6.5，遮棚可朝玩家突出。**不要套地標0.62/+5m**。
- 101是原尺寸地標模型，GLB不預套0.62或5m。由原sight/專用場景loader配置，不能送家具loader。
- 中正紀念堂、捷運維持各自原接口。不要將地標縮放套到捷運。
- 前景最大外簷有約0.025m跨tile邊界，若tile混用應檢查接縫；立面細節不等於碰撞體。
- 材質名稱中`emissive`代表需程式接回自發光，不依賴bloom；全部無圖片貼圖。
