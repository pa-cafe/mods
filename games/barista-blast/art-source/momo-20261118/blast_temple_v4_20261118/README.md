# 台北廟宇 v4：同風格低台座重製，尚未整合

本包只完成台北廟宇優先項，不是台北整關完成版，也不是可接受新舊混雜的最終版本。沒有修改 repo、正式服務或玩法。

## 本次做了什麼
- 原版 temple 並未在 v3 重製。已讀取 `pa-cafe/mods` 的 `8ab71ecac6cd6c971605206d8c1954f110df11bc` / `games/barista-blast/page/street3d-taipei.ts`，原碼隨附。
- 原版 foot=14m 的土丘托起雙層廟，頂端約36.7m。現在重新建模為低石階台座、橫向院落兩翼、弧面瓦頂、燕尾脊、紅柱、斗拱、格扇、燈籠與香爐。不是把原模型等比壓扁。
- 新台座5.4m、總高25.382m，總高度下降約30.8%。初稿22.38m在原鏡位會被捷運擋住太多，因此將台座微調到5.4m，既比原14m低很多，主屋簷仍能越過捷運。下層門窗依然部分被遮擋，這是保留既有地標位置/捷運的結果。
- 暖石材、陶紅、暗玉綠與少量金色使用 v3 的柔和調色。不是龍山寺考證複製品，而是保留原遊戲名稱及可辨識輪廓的風格化道具。
